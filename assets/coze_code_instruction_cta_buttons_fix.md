# 修复 Products 列表视图 CTA 按钮布局问题

## 问题
在 Products 页面的列表视图（横排左图右文）模式下，每张产品卡片底部有两个 CTA 按钮：
- "View Details"（描边按钮）
- "WhatsApp"（绿色实心按钮）

这两个按钮横向挤在一起，WhatsApp 按钮右侧被卡片边缘裁切，显示不完整。

## 修复要求

1. **确保两个按钮完整显示，不被裁切**
   - 检查按钮容器是否有 `overflow-hidden` 或固定宽度导致裁切
   - WhatsApp 按钮必须完整可见，包括右边距

2. **按钮布局优化**
   - 列表视图下，如果两个按钮横排放不下，可以改为上下堆叠（flex-col），或自适应换行（flex-wrap）
   - 按钮之间保持合理间距（gap-2 或 gap-3）
   - 确保按钮有足够的 padding，不会被压缩

3. **网格视图也检查**
   - 如果同时存在网格视图（上图下文），确保网格视图下的按钮布局也正常
   - 网格视图下按钮可以横排，但同样不能被裁切

4. **响应式**
   - 移动端列表视图下，按钮可以上下堆叠或等宽横排
   - 确保所有断点下按钮都完整显示

## 注意事项
- 不要改变产品名截断行为（这是正常的，用户点击查看详情）
- 只修复按钮布局和裁切问题
- 保持按钮的颜色样式不变（View Details 描边、WhatsApp 绿色 #21C96B）
- 修改前先读取 ProductsListClient.tsx 完整代码，定位按钮渲染部分再修改
- 修改后确保静态检查和类型检查通过
