# 移动端 Banner 16:9 比例收缩方案

## 核心目标
移动端 Banner 不再占 80vh 全屏高度，改为 16:9 宽短图片条，文字和按钮按比例收缩，确保"您想如何开始？"分流卡片在首屏可见。

## 1. Banner 高度（移动端 <768px）

- 移除当前 `min-height: 80vh` 或 `65vh`
- 改为 `aspect-ratio: 16 / 9`，宽度 100%
- 390px 宽时高度自动约 219px，375px 宽时约 211px
- 桌面端（≥768px）保持当前 75vh + aspect-ratio 16:9 不变（或直接统一用 16:9，但桌面端最小高度不低于 480px）

## 2. 图片处理

- 图片继续使用 `object-fit: cover` 铺满 16:9 容器
- `object-position: center` 保持中心构图
- 由于容器变矮，图片裁切范围大幅减小，不会出现主体被切一半的问题
- 首张 `loading="eager"`，其余 `loading="lazy"`

## 3. 渐变遮罩（移动端）

- 遮罩改为从底部向上加深，确保底部文字可读：
  ```css
  background: linear-gradient(
    to top,
    rgba(15, 42, 74, 0.92) 0%,
    rgba(23, 58, 99, 0.75) 40%,
    rgba(23, 58, 99, 0.3) 70%,
    rgba(23, 58, 99, 0.1) 100%
  );
  ```
- 遮罩覆盖整个 16:9 区域

## 4. 文字内容缩放（移动端）

在 16:9 容器内，文字叠加在底部渐变最深的区域：

- **标题**：从当前大号缩小至 `text-xl`（20px），`font-bold`，白色，最多 2 行
- **副标题**：缩小至 `text-sm`（14px），白色 80% 透明度，最多 2 行，`line-clamp-2`
- 标题和副标题间距：8px
- 文字区域 padding：左右 16px，底部 12px
- 文字垂直对齐底部（`justify-content: flex-end` 或 `items-end`）
- 如果标题+副标题在 16:9 内容纳不下，优先缩小副标题字号到 text-xs（12px）

## 5. CTA 按钮（移动端）

有两种布局可选，优先方案 A：

**方案 A：按钮放在 Banner 图片下方（Banner 外）**
- Banner 图片条（16:9）下方紧接一排按钮
- 按钮高度从 h-12 缩小到 h-10（40px）
- 字号 text-sm
- 两个按钮全宽上下堆叠，间距 8px
- 按钮区域左右 padding 16px，上下 padding 12px
- 背景色为页面底色（Warm White #F7F4EF 或白色）
- 优点：按钮不占用 Banner 图片空间，图片展示完整，按钮足够大可点击

**方案 B：按钮叠加在 Banner 底部**
- 按钮放在渐变遮罩区域内，标题下方
- 按钮高度 h-9（36px），字号 text-xs
- 两个按钮左右并排或全宽堆叠
- 优点：整体更紧凑；缺点：按钮较小

**请实施方案 A。**

## 6. 轮播指示器

- 保留在 Banner 图片条底部
- 缩小尺寸：当前项 w-6 h-1.5，其他项 w-1.5 h-1.5
- 与文字区域不重叠（如果重叠，将指示器下移到按钮区域或隐藏移动端指示器）
- 优先隐藏移动端轮播指示器，因为 16:9 高度紧凑，避免指示器和文字打架

## 7. 滚动提示

- 移动端不显示（已隐藏则保持）

## 8. 自动轮播

- 保持 5 秒自动切换
- 切换时文字内容跟随切换

## 9. 桌面端保持不变

- ≥768px：全屏背景 cover + 75vh 高度 + 渐变遮罩 + 内容在 40% 位置 + 并排按钮 + 滚动提示
- 不要因为移动端改动影响桌面端布局

## 10. 验证要求

- `pnpm ts-check` 通过
- `pnpm lint` 通过
- 在 375px、390px、430px 宽度下：
  - Banner 严格 16:9 比例，高度约 210-242px
  - 图片不被严重裁切
  - 标题最多 2 行，副标题最多 2 行，文字在底部渐变区清晰可读
  - 两个按钮在 Banner 下方全宽排列，高度 40px
  - "您想如何开始？"分流卡片标题在首屏内可见（不滚动即可看到）
- 桌面端 1920px 下布局不变
