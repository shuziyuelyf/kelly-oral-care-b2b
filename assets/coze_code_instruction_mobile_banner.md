# 移动端 Banner 布局重构

## 问题
当前移动端 Banner 使用桌面端横图 + object-fit:cover 全屏铺底，导致：
- 图片在竖屏上被严重裁切（手机屏幕上的文字只看到一半）
- 标题文字压在图片主体上，视觉混乱
- 80vh 过高，挤占下方分流卡片空间
- 渐变遮罩在移动端不够深，图片干扰文字阅读

## 解决方案：移动端图片改为装饰浮层

### 1. 移动端（<768px）布局重构

**不再使用全屏背景图 cover 模式**，改为：

- Banner 区域背景：纯海军蓝渐变 `linear-gradient(160deg, #0F2A4A 0%, #173A63 40%, #1E4D7B 100%)`
- 轮播图片缩小为装饰元素：宽度 55%，`position: absolute; right: -5%; bottom: 0; opacity: 0.35; object-fit: contain;`
- 图片作为半透明装饰浮在右下角，不裁切、不抢文字视觉
- 文字内容区域占据上方 55% 空间，左对齐，不和图片重叠
- CTA 按钮放在文字下方，完整可见

### 2. Banner 高度

- 移动端 `min-height` 从 `80vh` 改为 `65vh`
- 桌面端保持 `75vh` 不变
- 使用 `min-height` 而非固定 `height`，内容多时可自然撑开

### 3. 渐变遮罩调整

移动端由于图片变为装饰浮层：
- 不再需要全屏遮罩层
- 图片本身设置 `opacity: 0.35`，自然融入渐变背景
- 确保文字区域（左侧和上方）没有图片干扰

### 4. 文字样式（移动端）

- 标题字号适当缩小（当前可能偏大），确保在 375px 宽度不换行异常
- 副标题保持当前大小
- 两个 CTA 按钮（探索方案 + WhatsApp）宽度 100% 或 max-width: 280px，堆叠排列
- 按钮间距 12px

### 5. 桌面端（≥768px）保持不变

- 全屏背景图 + object-fit:cover
- 渐变遮罩
- 内容 40% 位置
- 底部滚动提示显示

### 6. 其他移动端细节

- 隐藏底部滚动指示器（移动端不需要，节省空间）
- 轮播指示器（小圆点/胶囊）保留，位置在底部 16px
- 图片加载时背景色为 #173A63，防止白屏

## 验证要求
- `pnpm ts-check` 通过
- `pnpm lint` 通过
- 在 375px（iPhone SE）、390px（iPhone 14）、430px（iPhone 14 Pro Max）宽度下：
  - 图片完整显示不裁切
  - 文字不与图片重叠
  - 两个按钮完整可见
  - Banner 不超过屏幕高度的 65%
- 桌面端 1920px 下效果不变
